# NutriGen 🥗

NutriGen is a premium nutrition management and biometric analytics web application designed for senior project evaluation. It provides students and health enthusiasts with real-time calorie tracking, personalized meal structures, and dedicated physical performance metrics.

---

## 🌟 Key Features & Implemented Modules
* **Dynamic Core Dashboard:** A premium dark-mode aesthetic featuring interactive glassmorphic card designs and high-contrast yellow highlights for immediate tracking visibility.
* **Workouts & Performance Tracking (`Workouts.jsx`):** A dedicated tracking module built to help users align their physical training routines with their daily biometric and caloric expenditure goals.
* **Integrated Support Interface (`Contact.jsx`):** A streamlined communication channel allowing users to query dietary support or technical assistance directly through the platform.
* **Fluid Layout Architecture:** A completely responsive flexbox and grid environment built using custom CSS tokens to ensure structural integrity across mobile and desktop displays.

---

## 🛠️ Technical Stack
* **Frontend UI Library:** ReactJS 
* **Build Engine:** Vite (Optimized production asset compilation)
* **Styling Framework:** Specialized Custom CSS (Utilizing glassmorphism and modern dark/yellow theme parameters)
* **Runtime Language:** JavaScript
